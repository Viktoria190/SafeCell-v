## 🚀 Функціонал сайту

## 🛠 Інструкція з розміщення на GitHub Pages
1. Розпакуйте ZIP-архів.
2. Створіть новий репозиторій на GitHub під назвою `safecell-ukraine`.
3. Завантажте всі файли з архіву у репозиторій.
4. Перейдіть у **Settings** -> **Pages**.
5. У розділі **Build and deployment** оберіть гілку `main` (або `master`) та збережіть (**Save**).
6. Ваш сайт буде доступний за адресою: `https://<ваш-username>.github.io/safecell-ukraine/`.
